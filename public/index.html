❓ အသုံးပြုနည်း လမ်းညွှန်

၀။ ပထမဆုံး တပ်ဆင်ခြင်း (One-Click)

Project folder ထဲရှိ Install-Terminal.bat ကို Right-click → Run as administrator ဖြင့် run ပါ။ Node.js, Git, OpenCode AI CLI, Build Tools, project dependencies, အခမဲ့ Model Config နှင့် Desktop Shortcut များကို အလိုအလျောက် တပ်ဆင်ပေးပါမည်။ အဆုံးတွင် OpenCode Login ဝင်ရန် မေးပါမည်။ နောက်မှ ဝင်လိုပါက Login-OpenCode.bat ကို Double-Click လုပ်ပါ။

၁။ စတင်ခြင်း

Desktop ပေါ်ရှိ Myanmar OpenCode Terminal icon (သို့မဟုတ်) Start-Terminal.bat ကို Double-Click ဖွင့်ပါ။ Server စတင်ပြီး Browser (Edge App Mode) အလိုအလျောက် ပွင့်လာပါမည်။

၂။ Project Folder ရွေးချယ်ခြင်း

Header ရှိ 📂 Browse ကို နှိပ်၍ App အတွင်း Folder Browser (Drive/ဖိုင်တွဲ စာရင်း) မှ Project Folder ရွေးပါ (သို့မဟုတ်) ✏️ ရိုက်ထည့်ရန် ဖြင့် path တိုက်ရိုက်ရိုက်ထည့်ပါ။ ယခင်သုံးခဲ့သော Project များကို Modal ထဲရှိ စာရင်းမှ တစ်ချက်နှိပ်၍ ပြန်ဖွင့်နိုင်ပါသည်။

၃။ မြန်မာလို Prompt ရိုက်၍ မေးမြန်းခြင်း

အောက်ခြေ Burmese Composer အကွက်တွင် မြန်မာလို ရိုက်ထည့်ပြီး Enter (သို့မဟုတ် Ctrl+Enter) နှိပ်ပါ။ OpenCode ထံသို့ prompt ရောက်ရှိသွားပါမည်။ Shift+Enter ဖြင့် စာကြောင်းအသစ် ဆင်းနိုင်ပါသည်။

၄။ OpenCode စတင်ခြင်း

Header ရှိ 🚀 OpenCode စတင်မည် (သို့မဟုတ်) 💬 စာဖတ်မုဒ် ခလုတ်ကို နှိပ်ပါ။ Terminal ထဲတွင် OpenCode TUI စတင်ပါမည်။

၅။ Web UI အသုံးပြုခြင်း

🌐 OpenCode Web UI tab သို့ သွားပြီး ▶️ Web Server စတင်မည် ကို နှိပ်ပါ။ ပထမဆုံးအကြိမ်တွင် Pairing Link ကို copy ကူး၍ Connect နှိပ်ပါ။

၆️⃣ အသုံးဝင်သော ခလုတ်များ

  • ⛔ ရပ်မည် (Ctrl+C) — running process ရပ်တန့်
  • ⎋ Popup ပိတ်မည် (Esc) — dialog/popup ပိတ်
  • ✨ Screen ပြင်မည် (Ctrl+L) — screen ပြန်ဆွဲသား
  • 🧹 Terminal ရှင်းမည် — screen ရှင်းလင်း
  • 🔄 ပြန်စမည် — terminal session ပြန်စ

၇️⃣ Zawgyi → Unicode

Zawgyi စာသား ကူးထည့်လိုက်ပါက ⚠️ Zawgyi ဖြစ်နေသည် badge ပေါ်လာပါမည်။ နှိပ်လိုက်ရုံဖြင့် Unicode သို့ ပြောင်းပေးပါသည်။

၈️⃣ မှတ်တမ်း (History)

📜 မှတ်တမ်း ခလုတ်ဖြင့် ယခင် prompt များကို ပြန်ကြည့်နိုင်ပါသည်။ Project Folder များကိုလည်း Modal ထဲရှိ စာရင်းမှ ပြန်ဖွင့်နိုင်ပါသည်။

၉️⃣ OpenCode 2 Login

အလွယ်ဆုံး — Login-OpenCode.bat ကို Double-Click လုပ်ပါ (Install-Terminal.bat ၏ အဆုံးတွင်လည်း မေးပါသည်)။ OpenCode Console → Personal ရွေး၍ browser ဖြင့် Sign in လုပ်ပါ (သို့မဟုတ် API key paste ချပါ)။ Terminal မှ တိုက်ရိုက်လုပ်လိုပါက opencode auth login။ အခြား Provider များအတွက် opencode auth login openai စသည် သုံးနိုင်ပါသည်။

🔟 Free Model များ (အခမဲ့)

နောက်ဆုံးစာရင်းကို Terminal တွင် opencode models ဖြင့် စစ်ဆေးပါ။ အသုံးများသော Free Model များ: deepseek-v4.1-flash-free (coding/debug), nemotron-3.5-super-vl-free (image/UI), glm-5.3-flash-free (အမြန် task), minimax-m3.1-flash-free။ ရွေးချယ်ရန် Tab 3 သို့မဟုတ် opencode run -m <model> သုံးပါ။

🔄 Tab 3 ၏ Model စာရင်းကို OpenCode မှ တိုက်ရိုက် (live) ရယူပါသည် — Free Model အသစ် ထွက်လာသည်နှင့် စာရင်းထဲ အလိုအလျောက် ပါလာပါမည်။ Free များကို 🆓 Free Model များ အုပ်စုတွင် ထိပ်မှ ပြပြီး 🔄 ပြန်ယူမည် ခလုတ်ဖြင့် ချက်ချင်း ပြန်လည် ရယူနိုင်ပါသည်။

👤 OpenCode Account စီမံခြင်းနှင့် ပြောင်းလဲခြင်း
